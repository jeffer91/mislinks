# Mis Links

Dashboard personal de Jefferson Villarreal para centralizar accesos a proyectos, sistemas y perfiles profesionales.

## Sitio

GitHub Pages: https://jeffer91.github.io/mislinks/

## Estructura

- **CV Profesional:** 24 accesos.
- **Sistema Docente:** 4 accesos.
- **Sistema de Titulación:** 5 accesos.
- Búsqueda instantánea.
- Filtros por categoría.
- Favoritos guardados en el navegador.
- Tema claro/oscuro.
- Diseño responsive para escritorio y móvil.

## Edición rápida

Los enlaces están centralizados en `projects.js`. Para agregar nuevos proyectos o accesos, basta con ampliar ese archivo.
